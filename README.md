# Training dashboard

Public, location-safe copy of a personal training dashboard: activities, health trends and events from Garmin data. Built daily from a private repo and served on GitHub Pages: https://sneakysquidz.github.io/training-dashboard/

Start and end points are rounded, the ends of every track are trimmed and frequently used places are masked. Health data is published encrypted. General wellness information, not medical advice.

This repo is generated; changes made here are overwritten by the next publish.
